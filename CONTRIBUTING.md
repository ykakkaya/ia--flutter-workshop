# Katkıda bulunma

Workshop katılımcıları ve projeyi geliştirmek isteyen herkes katkıda bulunabilir.

1. Depoyu fork'layın ve yeni bir dal açın: `git checkout -b ozellik/kisa-aciklama`
2. Değişikliğinizi yapın.
   - Backend için: `cd todo && composer run test`
   - Mobil için: `cd ftodo && flutter analyze`
3. Açıklayıcı bir commit mesajı yazın ve pull request açın.
4. Hata veya öneriler için issue şablonlarını kullanın.

Kurulum adımları için ana [README](README.md) dosyasındaki "Hızlı başlangıç" bölümüne bakın.
